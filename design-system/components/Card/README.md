# Card

White container with an optional title, subtitle and actions. `padding="none"` for tables and lists that run to the edge.

- `headingLevel` (2 to 6, default 3) is the level of the title's heading, so the outline of a page does not jump: under a PageHeader, whose title is the page's `h1`, a card is `headingLevel={2}` (2.3.0). The title looks the same at every level (`h5` style).
