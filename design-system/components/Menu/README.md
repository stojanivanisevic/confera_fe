# Menu

Dropdown of actions behind a button, usually the "more" button in a table row. Arrow keys move; the focused item shows the blue outline. Escape closes, and Escape or a choice gives the focus back to the button that opened the menu (2.2.0).

- Tab closes the menu and goes on to the control after it; Shift+Tab closes it and goes back to its button, as the ARIA menu-button pattern has it (2.3.0).
- Inside a Dialog or a Drawer, Escape closes the menu only, not the dialog around it (2.3.0).
