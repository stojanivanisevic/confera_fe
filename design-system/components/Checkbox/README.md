# Checkbox

Checkbox with label for consents and multi-choice options. A required consent: `required` (adds " *"), and when it is missing `status="error"` with a `message` that says what to do; the message is tied to the box (2.2.0).

Source: Figma "checkbox" (default, selected, focus, selected focus). Box 17.5px, 4px radius. Since version 2: checked is a `brand-orange` fill with a `brand-orange-strong` border and an `on-brand` (near-black) check; keyboard focus shows the blue `focus-ring` (a 1px white and a 3px blue ring), as every field. On a touch screen the whole row is a target of 44px high, and a box without a text is 44 x 44 (2.3.0).
