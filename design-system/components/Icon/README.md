# Icon

Lucide icon by name, drawn with the current text colour.

The Figma file uses Lucide names (mail, alert-circle, check-circle-2, x, check). The type `IconName` lists every icon (45 in version 2, 58 since 2.6.0):

- From the Figma file: mail, alert-circle, check-circle-2, check, x, chevron-down, arrow-left, arrow-right, arrow-up-right, upload, info.
- For the admin: search, eye, eye-off, calendar, chevron-up, chevron-left, chevron-right, chevrons-up-down, plus, trash, more, file, alert-triangle, menu, users, home, settings, inbox, send, refresh, filter, minus.
- Added in version 2 (Lucide 1.56.0): download, copy, external-link, edit, globe, log-out, user, lock, clock, file-text, credit-card, link.

An icon without a `title` is decorative and hidden from assistive technology; give the control around it a name.
- **Added in 2.4.0** (Lucide, ISC): `bold`, `italic`, `underline`, `list`, `list-ordered`, `undo`, `redo`, `corner-down-left` (a line break), `braces` (a placeholder), the toolbar of a rich-text editor (M2-ISS-07); and `circle`, an empty circle for a line not done yet.
- **Added in 2.6.0** (Lucide, ISC): `image` (an image in the toolbar of the mail-template editor), `message-square` (an internal note) and `rotate-ccw` (reopen).
