# CircleButton

Large round call to action, used for "Become a member" across the site.

Source: Figma "Circle Button" (drawn about 190px wide, text rotated). Size and ring width were measured from the screenshot.

- Place it once per page, overlapping a section edge as in the Home and Membership designs.
- `tilt={false}` keeps the label straight; `size` changes the diameter.
