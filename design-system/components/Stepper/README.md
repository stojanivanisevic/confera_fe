# Stepper

Shows the steps of a long form or a process and where the person is. Completed steps can be revisited with `onStepClick`.

- Horizontal shows labels from 720px (only the current one below); vertical always shows them.
- A finished step that can be revisited is a button with the blue focus outline (2.3.0; it showed the browser's own ring), a target of 44 x 44 on a touch screen.
