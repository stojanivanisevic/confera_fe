# ArrowButton

Round arrow button for sliders, carousels and card links.

Source: Figma "Arrow Button" and the round buttons beside it; sizes were measured from the screenshot.

- `variant`: `outline` (dark ring, slider on light grounds), `outline-orange`, `orange` (filled), `white` (on photos and dark grounds).
- `direction`: `left`, `right`, `up-right`. Always pass `label` when the arrow alone does not say where it goes.
