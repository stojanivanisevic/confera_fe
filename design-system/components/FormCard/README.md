# FormCard

White card that holds a form, with an intro line, a two-column field grid and actions.

Source: Main Form page; radius and padding were measured from the screenshot.

- Fields flow into two columns from 460px and stack below. Give a child `className="ud-span-all"` to span both columns.
- Use it on the warm `background` with the page title (h1) and a short intro above the card.
