# Switch

On/off toggle for settings that take effect at once ("Send confirmation email", "Form is open"). Use Checkbox inside forms that are submitted.

- Off is a white track with a `neutral-700` border and thumb; on is a `brand-orange-strong` track with a white thumb (2.3.0). The two tracks differ by 5.38:1, so the state is not read from the thumb's place alone (it was 1.33:1).
