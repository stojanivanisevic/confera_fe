# Changelog

All notable changes to `confera_fe`. Versions follow SemVer; `confera_be` carries the same version at each milestone (ADR-19). The design system has its own changelog in `design-system/CHANGELOG.md`.

## 0.1.0 (unreleased): foundations, risk spikes and design system v2

### Added
- **Workspace and toolchain (M1-FE-01).** pnpm 11.28.2 workspace on Node 22 with one Next 16.4 application and the packages `ui`, `form-renderer`, `embed-loader` and `api-client`; TypeScript 6.0.3 strict; `pnpm check`. Supply-chain rules: frozen lockfile, exact versions, a 3-day minimum release age, build scripts by name, strict engines and peers, a vulnerability audit that fails on high, a secret scan. Lint rules with planted violations: no second UI kit, no colour literal, raw markup only in the one reviewed component, the environment only in the configuration module, no server actions. Framework settings: telemetry off, no version header, no public source map, image optimiser off; the production build is checked against the declared routes.
- **Design system 2.0.0 (M1-FE-03, M1-FE-06).** `tokens.css`; the contrast tokens of ADR-22 (`on-brand`, `brand-orange-strong`, `danger-hover`, a darker `success-strong`), `brand-orange` unchanged; self-hosted Manrope and Inter; complete types; 12 icons; translatable labels and `LabelsProvider`; the accessibility fixes; 16px controls on touch devices; version, changelog and checksums. See `design-system/CHANGELOG.md`.
- **The adapter (M1-FE-02).** `@confera/ui` wraps the design-system script, unchanged, so that it renders on the server and hydrates under React 19; `pnpm ds:build`, `pnpm ds:check`, `pnpm ds:visual`, `pnpm ds:snapshot`; the component gallery (test builds only).
- **The embed (M1-FE-04).** The snippet of decision G2-17 (a), the frame page `/embed/[form]`, the hosted page `/f/[form]`, the frame's height reporter, and the spike form with a draft storage that survives a browser that refuses storage.
- **API client (M1-FE-05).** The contract of `confera_be` vendored with a lock, types generated on TypeScript 6.0.3, `pnpm api:sync` and `pnpm api:check`; the admin home asks `GET /api/v1/meta` and stops on another major version.
- **Security headers and host separation (M1-FE-07).** Headers by kind of page in one place; `frame-ancestors 'none'` as the default and the site list only on the frame page; a nonce per response and `no-store` on every page; the baseline policy report-only; admin and public routes each answered only on their own host name; `/api/v1` and `/public/v1` forwarded with the `Host` header kept; the application refuses to start on a bad configuration.
- **Tests.** Unit tests (Vitest), browser tests on Chromium, Firefox and WebKit (Playwright) with a hostile harness site, and accessibility scans (axe, WCAG 2.1 A and AA).
- **Test engineering (M1-QA-01, M1-QA-03).** `pnpm test:supply-chain`, the last step of `pnpm check`: planted fake secrets, a vulnerable package and an unlisted build script must each be caught; the install settings held by a test; the bans of the lint held on the syntax tree in any spelling; browser probes at 320 px and under zoom, with a resizing or forging conference site, failing storage, the keyboard only and reduced motion; odd `Host` headers.
- **Cross-repo smoke test (M1-QA-02).** With `CONFERA_E2E_API_ORIGIN=http://127.0.0.1:3001` the browser tests run in front of a real `confera_be` that was started by its documented commands, and the project `real-api` asks what only the real API can answer (README, section 6). The variable takes an address of this machine only; the run first asks whether the API is ready.

### Fixed
- **The secret scan catches a secret that has no format (F1).** A literal value bound to a name like a secret fails `pnpm secrets`, in any syntax where a name gets a value. The rule and the scanner are those of `confera_be` (scanner 1.0.0): `scripts/secret-assignments/` is copied from there unchanged with its manifest (`pnpm secrets:sync`); its self-test, with both corpora and the manifest, runs in the unit tests, and a lock holds the version and the manifest, compared with the checkout of `confera_be` next to this one when there is one. This repository follows the rule: two labels of the design system are renamed (design system 2.1.0), and so is a rule of the style lint (`unknown-custom-property`).
- **The focus stays in a Repeater when a row is removed (F2, WCAG 2.4.3).** Design system 2.0.1; see `design-system/CHANGELOG.md`.
- **Text typed before the form is attached is kept (F3).** The fields of a form are plain controls that the page reads through a store (`createFormValueStore`, `useFormValues`, `useFormRef`); no render writes into a control the author has touched, and a draft fills only untouched fields.
- **The account guard also stops a run that is under way.** The "switched off" marker was read only before a run. Every worker now reads it before it starts a browser, of any engine. The README says what the guard cannot see: a successful logon sets Windows' count back to zero.
- **Browser tests far from their limits.** WebKit tests of a few seconds took 40 to 60 s of their 60 s limit as soon as three workers ran at once: the trace recorded a film strip of every frame, WebKit paints at device scale 2 without a graphics card, and the gallery never stops painting. The trace is now recorded without the film strip (a failed test still has its actions with the page as it was, and a picture of the failure); the gallery test that did the work of nine components, and the accessibility tests that scanned three or four pages or states, are one test per kind of behaviour, page or state; a check asked 53 times is asked once. The two files whose tests load or scan the whole gallery run their tests one after the other.
- **`pnpm dev` and `pnpm start` listen on loopback outside prod (E3).** Next listened on every address of the machine, and through its forwarding of `/api/v1` (with the client's `Host`) reached an API that itself listens on loopback only. The address is `LISTEN_HOST`, by default `127.0.0.1` outside `prod` and `0.0.0.0` on `prod`; on `local`, `dev` and `test` anything but a loopback address, and any `-H`/`--hostname`, stops the start. The same rule as in `confera_be`.
- **The two surfaces differ in host name, not only in port or scheme (E4).** A cookie does not tell ports apart, so one name on two ports carried the admin's session to the public pages. The same rule as in `confera_be`.
- **The height of an embedded form follows on sites that run scripts late or put the frame in later (E7).** The inline lines looked the frame up once, when they ran. They now look it up when a message arrives, by the window that sent it, and make a frame that already shows its page one pixel taller so that it tells its height again; the frame tells its height again whenever the page changes its size. A snippet pasted before this change keeps the old behaviour until it is pasted again.
- **A field may have any name (E9).** The values of a form are kept in an object without a prototype, so a field named `__proto__`, `constructor` or `toString` keeps its answer.
